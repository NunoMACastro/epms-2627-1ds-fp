## Como está organizado

Há uma pasta por percurso e, dentro dela, uma pasta por aula. O nome da pasta
começa pelo código da aula e continua com o assunto, para que se perceba pelo
nome o que lá está dentro.

```text
algoritmos/     ALG01 a ALG05   resolver problemas antes de escrever código
c/              C01 a C10       programação estruturada em C
python/         PY01 a PY10     aplicações em Python 3
avaliacoes/                     enunciados de avaliação, publicados na altura própria
```

Por exemplo, a pasta `c/C06-arrays-e-percursos-seguros/` reúne tudo o que
pertence a essa aula. Dentro de cada pasta, os nomes dos ficheiros dizem o que
cada um é:

| Ficheiro | O que é |
| --- | --- |
| `guia.md` | Os apontamentos da aula, para ler e consultar |
| `enunciado.md` | A ficha de exercícios ou o laboratório |
| `exemplo.c`, `exemplo.py` | O programa completo demonstrado na aula |
| `dados/` | Ficheiros de dados usados nos exercícios |

As resoluções não estão neste repositório.
