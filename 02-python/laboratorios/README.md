# Laboratórios de Python

Um laboratório faz-se no computador, passo a passo: constróis uma coisa concreta do princípio ao fim. Cada passo diz o que fazer, porquê e o que deves ver. No fim de cada fase, confirmas que tudo funciona antes de avançares. O caminho tem a solução à vista, e só os desafios do fim ficam para ti.

Um laboratório não é uma ficha de exercícios. No laboratório, aprendes a fazer com o texto a guiar-te. Na [ficha](../exercicios/README.md), treinas sozinho, sem a solução à vista. A matéria de cada tema está no guia, na pasta da área, e o [índice da área](../README.md) liga a cada um. Se precisares de a rever, cada fase do laboratório tem a ligação "Rever", direita à secção do guia. Em cada tema, o laboratório vem antes da ficha.
